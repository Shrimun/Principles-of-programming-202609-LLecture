# Principles of Programming – Assessment 1

**Module:** ITS72604 – Principles of Programming  
**Assessment:** Assessment 1  
**University:** Taylor's University  
**Semester:** September 2026

## About

This repository contains the source code, pseudocode, UML diagrams, and related materials for Assessment 1 of the Principles of Programming module.

The assessment is based on a **Smart Campus EV Charging and Parking Management System**.

## Assessment Structure

### Task 1 – Pseudocode
Contains the structured pseudocode for the EV charging and parking management system.

- `Task - 1/Task_1_Pseudocode.txt`

### Task 2 – Procedural Python
Contains the procedural Python implementation of the EV charging fee calculation system.

- `Task - 2/ev_charging_procedural.py`

The program includes:
- EV charging fee calculation
- Member discounts and first-time user waiver
- Green Eco-Pass discount
- Peak-hour surcharge
- Idle parking surcharge
- Lost RFID replacement fee
- Continuous vehicle processing

### Task 3 – UML Diagrams
Contains the UML diagrams for the object-oriented solution.

- `Task - 3/use_case_diagram.png`
- `Task - 3/class_diagram.png`

The diagrams include:
- UML Use Case Diagram
- UML Class Diagram
- Inheritance
- Composition
- Encapsulation
- Polymorphism

### Task 4 – Object-Oriented Python
Contains the object-oriented Python implementation based on the Task 3 UML Class Diagram.

- `Task - 4/ev_charging_oop.py`

The program demonstrates:
- Classes and objects
- Inheritance
- `super().__init__()`
- Private attributes
- Getters and setters
- Setter validation
- Method overriding
- Polymorphism
- EV charging billing
